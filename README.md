# Uczenie maszynowe — kurs 2026

Materiały do zajęć z uczenia maszynowego. Z każdych zajęć znajdziesz tutaj prezentację, notebook z ćwiczeniami oraz — jeśli jest — zadanie do wykonania.

## Jak zacząć

```bash
git clone <URL-repozytorium>
cd ml-course-pg-2026
pip install -r requirements.txt
jupyter notebook
```

Alternatywnie możesz otwierać notebooki w [Google Colab](https://colab.research.google.com/) — bez instalowania czegokolwiek lokalnie.
